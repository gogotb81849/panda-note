                熊猫笔记 - 快速启动指南
================================================================

📋 前提条件
----------------------------------------------------------------
1. Node.js 18+  (已安装: v24.14.0) ✅
2. PostgreSQL 12+ 数据库

🚀 启动步骤（按顺序执行）
----------------------------------------------------------------

第一步：准备数据库（只需要做一次）
----------------------------------------------------------------
1. 确保 PostgreSQL 已启动
2. 在 PostgreSQL 中执行以下 SQL：

   CREATE DATABASE navlog;
   CREATE USER navlog WITH PASSWORD 'NavLog2026!@#';
   GRANT ALL PRIVILEGES ON DATABASE navlog TO navlog;
   \c navlog
   GRANT ALL ON SCHEMA public TO navlog;

3. 双击运行：初始化-数据库.bat

第二步：启动后端服务
----------------------------------------------------------------
双击运行：启动-后端.bat
- 后端地址: http://localhost:3002

第三步：启动前端服务
----------------------------------------------------------------
双击运行：启动-前端.bat
- 前端地址: http://localhost:3000
