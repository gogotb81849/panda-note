## 一、项目现状分析

### 1.1 技术栈
- **前端**：Nuxt3 + Vue3 + Element Plus + Pinia + TailwindCSS
- **后端**：NestJS + Prisma + PostgreSQL
- **AI**：火山引擎 doubao-pro（通过环境变量配置）
- **部署**：PM2管理进程，Python自动化部署脚本

### 1.2 现有核心资产
- 4级角色权限体系（admin → shore_supervisor → ship_political_instructor → 船员）
- AI简报生成模块（ai-brief）已接入火山引擎
- 文件上传与Excel解析能力（SharedFile）
- 船员管理（CrewMember + 生日提醒 + 农历转换）
- 文件收集系统（FileCollection + FileSubmission，可复用为健康表收集）
- 日记/日程/任务完整体系
- 操作日志（OperationLog）支撑审计追踪

### 1.3 全局强制约束
1. 移动端仅录入/查看/上传，无AI计算
2. 网页端承载全部AI运算
3. 所有AI输出强制草稿化，人工终审
4. 垂直层级流转，拒绝平行协作
5. 原始数据/文件永久保留，AI不篡改
6. 所有新页面沿用现有UI体系（配色、圆角、间距、按钮风格）

### 阶段一：MVP核心功能 - 健康排查系统
**目标**：完成月度船舶船员健康排查AI全自动汇总系统

#### 1.1 数据库设计
```prisma
// 健康排查表上传记录
model HealthReportUpload {
  id            Int       @id @default(autoincrement())
  teamCode      TeamCode
  shipId        Int
  uploadDate    DateTime  @default(now())
  month         String    // "2026-06"
  
  // 文件信息
  fileName      String
  filePath      String
  fileSize      Int
  
  // 校验结果
  validationResult String  // pass/fail/ai_fixed
  validationErrors Json?   // 具体错误 [{field, message}]
  aiFixNotes    String?   // AI容错修复备注
  
  // 统计数据
  crewCount     Int       @default(0)
  healthAbnormalCount Int @default(0)
  psychAbnormalCount Int  @default(0)
  abnormalDetails Json?   // 异常船员明细
  
  // 状态
  status        String    @default("pending") // pending/reviewed/archived
  uploadedBy    Int
  reviewedBy    Int?
  reviewedAt    DateTime?
  
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  
  @@index([teamCode, shipId, month])
  @@index([teamCode, status])
}

// 月度健康汇总
model MonthlyHealthSummary {
  id            Int       @id @default(autoincrement())
  teamCode      TeamCode
  month         String    // "2026-06"
  
  // AI报告
  reportContent String    @db.Text  // AI生成的报告草稿
  isDraft       Boolean   @default(true)
  isEdited      Boolean   @default(false)
  finalizedBy   Int?
  finalizedAt   DateTime?
  
  // 统计数据
  totalShips    Int       @default(0)
  normalShips   Int       @default(0)
  abnormalShips Int       @default(0)
  unsubmittedShips Int    @default(0)
  totalCrew     Int       @default(0)
  healthAbnormalTotal Int @default(0)
  psychAbnormalTotal Int  @default(0)
  
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  
  @@unique([teamCode, month])
}
```

## 三、技术规范

### 3.1 UI规范
- 主色调：#409EFF（Element Plus默认蓝）
- 圆角：8px（卡片）、4px（按钮）
- 间距：16px（模块间）、8px（元素间）
- 字体：系统默认，标题16px/18px，正文14px

### 3.2 代码规范
- TypeScript严格模式
- 前端组件使用 `<script setup lang="ts">`
- 后端使用DTO + Service + Controller分层
- 所有AI接口返回格式统一：`{ success, data, error, isDraft }`

### 3.3 Excel校验规则
- 仅允许.xlsx格式
- 标准表头：姓名、生理健康、心理健康、异常备注
- 固定列数：至少4列
- 最小行数：1行（表头）+ 1行（数据）
- 禁止空行插入
