# 熊猫笔记 - 部署文档

## 环境要求

- Node.js 18+
- PostgreSQL 14+
- npm 或 yarn 或 pnpm

## 项目结构

```
nav-log-system/
├── backend/          # NestJS 后端
├── frontend/         # Nuxt 3 前端
├── docs/            # 文档
└── docker/          # Docker 配置
```

## 数据库设置

1. 创建数据库：
```sql
CREATE DATABASE nav_log_system;
```

2. 配置环境变量：
编辑 `backend/.env` 文件：
```
DATABASE_URL="postgresql://username:password@localhost:5432/nav_log_system?schema=public"
JWT_SECRET="your-secret-key-here"
```

3. 运行数据库迁移：
```bash
cd backend
npx prisma migrate dev
npx prisma db seed
```

## 后端部署

1. 安装依赖：
```bash
cd backend
npm install
```

2. 开发模式运行：
```bash
npm run start:dev
```

3. 生产模式构建：
```bash
npm run build
npm run start:prod
```

4. 后端服务地址：http://localhost:3001

## 前端部署

1. 安装依赖：
```bash
cd frontend
npm install
```

2. 开发模式运行：
```bash
npm run dev
```

3. 生产模式构建：
```bash
npm run build
npm run preview
```

4. 前端服务地址：http://localhost:3000

## Docker 部署

### 使用 Docker Compose

```bash
docker-compose up -d
```

### 单独构建镜像

后端：
```bash
cd backend
docker build -t nav-log-backend .
```

前端：
```bash
cd frontend
docker build -t nav-log-frontend .
```

## 功能模块

### 已实现功能

1. **用户认证**
   - 登录/登出
   - JWT Token 认证
   - 登录失败锁定（5次）
   - 记住登录（7天）

2. **日程管理**
   - 月/周/日三种视图
   - 新建/编辑/删除日程
   - 在岗人员匹配
   - SOP 流程填充
   - 优先级和状态管理

3. **高级查询**
   - 多条件筛选
   - Excel 导出
   - 分页列表

4. **船舶资料**
   - 船舶信息管理
   - 船员配置
   - 在船人员查询

5. **人员履历**
   - 人员基本信息
   - 在船历史记录

6. **SOP 流程**
   - 流程模板管理
   - 内容编辑

7. **案例库**
   - 公开案例展示
   - 案例分类

8. **字典管理**
   - 数据字典维护
   - 分类管理

9. **操作日志**
   - 用户操作记录
   - 日志查询

### 开发中功能

1. **AI 工作简报**
   - 自动生成周报/月报
   - 工作内容总结

2. **系统管理**
   - 数据导入/导出
   - 用户管理
   - 系统设置

## 注意事项

1. 首次部署请确保数据库连接正常
2. 生产环境请修改 JWT_SECRET
3. 建议使用 HTTPS 协议
4. 定期备份数据库
