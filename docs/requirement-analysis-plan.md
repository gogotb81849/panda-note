## 六、政委派任甘特图管理功能（2026-08-01 新增）

### 6.1 需求背景

陈先生需要直观管理33艘船舶的政委派任情况。现有 `admin/staff-assignments.vue` 和 `staff-history.vue` 两个分散页面，用表格展示派任记录，但无法直观看到全局时间分布和在船时长预警。

### 6.2 核心需求

1. **甘特图视图**：每艘船一行（33行），横向时间轴按月显示，每个派任期用彩色横条表示
2. **在船时长颜色分级**（国际公约标准）：
   | 在船时长 | 状态 | 颜色 | 含义 |
   |---------|------|------|------|
   | 0 ~ 6个月 | 正常 | 🟢 绿色 | 合同期内 |
   | 6 ~ 8个月 | 关注 | 🟡 黄色 | 即将到期 |
   | 8 ~ 10个月 | 预警 | 🟠 橙色 | 应尽快换班 |
   | 10 ~ 11个月 | 极限 | 🔴 红色 | 必须立即换 |
   | > 11个月 | 违规 | ⚫ 深红+闪烁 | 违规！ |
   | 已下船 | 结束 | ⚫ 灰色 | 历史记录 |
   | 船舶无政委 | 空缺 | 深红底色 | 需立即派任 |
3. **同行多段色条**：同一艘船行内可显示历任政委（前任灰色 + 现任按时长分色）
4. **时间轴可左右滚动**：查看历史和未来派任
5. **今日竖线标记**
6. **点击色条弹出编辑菜单**：修改上船日期 / 下船登记 / 休假 / 一键换班 / 删除
7. **点击政委名弹出个人卡片**：Phase 2 完善，Phase 1 先显示"建设中"

### 6.3 页面融合方案

将 `staff-assignments.vue` 和 `staff-history.vue` 合并为**统一政委管理页面**，用 Tab 切换三种视图：

| Tab | 内容 | 数据来源 |
|-----|------|---------|
| 甘特图视图（默认） | ECharts Custom Series 甘特图 | StaffAssignment 表 |
| 派任列表视图 | 原表格 + 所有弹窗（上船/下船/休假/换班/编辑/删除）| StaffAssignment 表 |
| 任职履历视图 | 原表格 + 弹窗 | StaffHistory 表 |

### 6.4 技术方案

- **前端**：ECharts 6.1.0 Custom Series（已安装，无需新依赖）
- **后端**：无需改动，现有 `StaffAssignment` 表和 API 完全满足
- **交互**：点击色条 → Element Plus Popover 编辑菜单
- **时间轴**：ECharts dataZoom 支持左右滚动
