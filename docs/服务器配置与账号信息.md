| SSH端口 | 22 |
| 用户名 | root |
| 认证方式 | SSH 密钥（ed25519 密钥对）|
| 私钥路径 | `~/.ssh/panda-nav-server` |
| 密码（回退方案）| BTroot260318 |

### 生成与部署密钥（首次部署时执行）

```bash
# 1. 在本地生成 ed25519 密钥对（推荐，比 RSA 更安全且文件更小）
ssh-keygen -t ed25519 -f ~/.ssh/panda-nav-server -C "nav-log-deploy"

# 2. 将公钥部署到服务器
ssh-copy-id -i ~/.ssh/panda-nav-server root@106.14.57.62

# 3. 测试密钥登录（不需要输入密码）
ssh -i ~/.ssh/panda-nav-server root@106.14.57.62

# 4. 在项目根目录的 .env 中写入私钥路径
#    SSH_KEY_PATH=~/.ssh/panda-nav-server
```

### 服务器端安全配置（可选但推荐）

```bash
# /etc/ssh/sshd_config 建议配置
PubkeyAuthentication yes        # 启用公钥认证
# PasswordAuthentication no      # 禁用密码认证（⚠️ 确保密钥生效后再关闭）
PermitRootLogin prohibit-password # 禁止root密码登录，但允许密钥登录
```

## 六、.env 文件模板（生产部署）

> ⚠️ **请务必将以下配置写入项目根目录的 `.env` 文件，不要修改本模板文件。**
> 
> `.env` 文件示例（完整模板见根目录 `.env.example`）：

```
APP_VERSION=1.1.0.0044
DATABASE_URL=postgresql://navlog:navlog123@127.0.0.1:5432/navlog?schema=public
JWT_SECRET=<请用 openssl rand -hex 64 或类似命令生成随机密钥>
SERVER_IP=106.14.57.62
SERVER_USER=root
SERVER_SSH_PORT=22
SSH_KEY_PATH=~/.ssh/panda-nav-server
SSH_KEY_PASSPHRASE=（密钥保护密码，如未设置则留空）
AI_API_KEY=<你的 AI 服务密钥>
```

> 生成 JWT_SECRET 命令：
> ```bash
> # 方式一：OpenSSL
> openssl rand -hex 64
> 
> # 方式二：Python
> python -c "import secrets; print(secrets.token_hex(64))"
> 
> # 方式三：Node.js
> node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
> ```
