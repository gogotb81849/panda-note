- **ORM（对象关系映射）**：就像翻译官，把数据库的表格转换成代码能理解的对象，让程序员不用写复杂的 SQL 语句

- **消息队列**：就像快递分拣中心，把耗时任务（如 AI 分析）放到后台处理，用户不用等待

### 8.2 双 Token 认证流程图（✅ 已实现）

```
用户登录（账号 + 密码）
    ↓
bcrypt 校验 → 签发 Access Token（2h） + Refresh Token（7d）
    ↓
客户端存储 Access Token（内存） + Refresh Token（HttpOnly Cookie）
    ↓
请求 API → Authorization: Bearer <access_token>
    ↓
Access Token 过期（401）→ 自动 POST /api/auth/refresh
    ↓
校验 Refresh Token（查 Redis 黑名单 + 验证签名）
    ↓

```

**深入浅出说明**：

```prisma
// ============================================================
// ✅ 新增 DiaryScheduleRelation 表
// （日记 ↔ 已完成日程）多对多关联表
// ============================================================
model DiaryScheduleRelation {
  id          Int      @id @default(autoincrement())
  teamCode    TeamCode
  diaryId     Int      // 关联日记
  scheduleId  Int      // 关联已完成日程
  createdAt   DateTime @default(now())

  diary    Diary    @relation(fields: [diaryId], references: [id])
  schedule Schedule @relation(fields: [scheduleId], references: [id])

  @@unique([diaryId, scheduleId])  // 避免重复关联
  @@index([teamCode, diaryId])
  @@index([teamCode, scheduleId])
}

// ============================================================
// ✅ 修改 Diary 模型
// ============================================================
model Diary {
  // ===== 保留现有字段 =====
  id            Int       @id @default(autoincrement())
  userId        Int
  teamCode      TeamCode
  shipId        Int?
  date          DateTime
  content       String    @db.Text  // 自由叙事文字
  // ... 其他字段省略

  // ===== 分类字段：保留但改为"可选/仅继承自 Schedule" =====
  categoryFirst String?  // 一级分类（自动从关联 schedule 继承）
  categorySecond String? // 二级标题（自动从关联 schedule 继承）
  categorySource String? @default("manual") // manual=手动填写 / auto=自动继承

  // ===== 新增：多对多关联已完成日程 =====
  relatedSchedules DiaryScheduleRelation[]

  // ===== 保留字段 =====
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

// ============================================================
// ✅ Schedule 模型（新增反向关联 + 组合索引）
// ============================================================
model Schedule {
  // ===== 保留全部现有字段 =====
  id           Int            @id @default(autoincrement())
  teamCode     TeamCode
  recordDate   DateTime
  shipId       Int?
  firstType    String         // 一级分类（统计主数据源）
  secondType   String         // 二级分类（统计主数据源）
  finishStatus ScheduleStatus @default(pending) // 完成状态（统计主数据源）
  // ... 其他字段省略

  // ===== 新增：反向关联日记 =====
  relatedDiaries DiaryScheduleRelation[]

  // 保留索引
  @@index([teamCode, recordDate])
  @@index([teamCode, shipId])
  // ===== ✅ 新增：为统计优化的组合索引 =====
  @@index([teamCode, finishStatus, recordDate])
  @@index([teamCode, firstType, secondType])
}
```

```typescript
export const useLogCollector = () => {
  // 捕获 JavaScript 错误
  window.addEventListener('error', (event) => {
    collectError({
      message: event.message,
      stack: event.error?.stack,
      url: window.location.href,
    });
  });

  // 捕获 Promise 未处理异常
  window.addEventListener('unhandledrejection', (event) => {
    collectError({
      message: `Promise rejected: ${event.reason}`,
      stack: event.reason?.stack,
      url: window.location.href,
    });
  });

  // 捕获 API 错误
  const logApiError = (url: string, method: string, status: number, response: any) => {
    collectError({
      message: `API error: ${method} ${url} returned ${status}`,
      apiUrl: url,
      apiMethod: method,
      apiStatus: status,
      metadata: response,
    });
  };

  // 定期上传日志
  const uploadLogs = async () => {
    if (logQueue.length === 0) return;
    
    await api.clientLogs.upload(logQueue);
    logQueue = [];
  };

  // 每 5 分钟上传一次
  setInterval(uploadLogs, 5 * 60 * 1000);
};
```

## 二十、版本管理机制设计与实现

### 20.1 版本号规范（✅ 已实现）

**4 段语义化版本号**：`major.minor.patch.build`

- **major**：主版本号，重大架构变更时递增（如 1.0.0.0 → 2.0.0.0）
- **minor**：次版本号，新增功能时递增（如 1.1.0.0 → 1.2.0.0）
- **patch**：补丁版本号，修复 bug 时递增（如 1.1.1.0 → 1.1.2.0）
- **build**：构建号，每次构建自动递增（如 1.1.1.0045 → 1.1.1.0046）

**深入浅出说明**：
- **语义化版本**：就像书的版次，"第 2 版第 3 次印刷"表示重大更新 2 次，小更新 3 次。版本号让用户知道更新的重要程度

### 20.2 前后端版本同步（✅ 已实现）

**版本号来源**：

| 端 | 来源 | 读取方式 |
|----|------|---------|
| 前端 | `frontend/package.json` | `nuxt.config.ts` 中 `public.appVersion` 读取 |
| 后端 | `backend/package.json` | `VersionService.getVersion()` 读取 |

**版本同步机制**：

```typescript
// ✅ 后端版本服务
@Injectable()
export class VersionService {
  getVersion(): string {
    const packageJson = require('../../package.json');
    return packageJson.version;
  }

  // 版本比较算法
  compareVersions(v1: string, v2: string): number {
    const parts1 = v1.split('.').map(Number);
    const parts2 = v2.split('.').map(Number);

    for (let i = 0; i < 4; i++) {
      if (parts1[i] > parts2[i]) return 1;
      if (parts1[i] < parts2[i]) return -1;
    }
    return 0;
  }

  // 检查是否需要更新
  async checkUpdate(clientVersion: string) {
    const serverVersion = this.getVersion();
    const needsUpdate = this.compareVersions(serverVersion, clientVersion) > 0;

    return {
      currentVersion: serverVersion,
      clientVersion,
      needsUpdate,
      updateType: this.getUpdateType(serverVersion, clientVersion),
      updateMessage: this.getUpdateMessage(serverVersion, clientVersion),
    };
  }
}
```

### 20.3 防降级保护（✅ 已实现）

**核心规则**：

1. ✅ `服务器版本 > 客户端版本` → 提示升级（needsUpdate = true）
2. ✅ `服务器版本 = 客户端版本` → 不升级（needsUpdate = false）
3. ✅ `服务器版本 < 客户端版本` → 不升级（needsUpdate = false）
4. ✅ 任何解析失败 → 不升级（needsUpdate = false）

**深入浅出说明**：
- **防降级保护**：就像手机系统更新，只能从旧版本升级到新版本，不能从新版本"降级"到旧版本，防止系统混乱

### 20.4 PWA 自动更新插件（✅ 已实现）

**文件**：`frontend/plugins/pwa-update.client.ts`

```typescript
// ✅ PWA 自动更新插件
export default defineNuxtPlugin((nuxtApp) => {
  if (process.client) {
    // 防循环保护：10 分钟内最多检查 3 次
    let checkCount = 0;
    const maxChecks = 3;
    const checkInterval = 10 * 60 * 1000; // 10 分钟

    const checkForUpdate = async () => {
      if (checkCount >= maxChecks) return;

      const clientVersion = useRuntimeConfig().public.appVersion;
      
      try {
        const result = await $fetch('/api/version/check', {
          method: 'POST',
          body: { clientVersion },
        });

        if (result.needsUpdate) {
          // 二次校验，确保不降级
          const shouldUpdate = compareVersions(result.currentVersion, clientVersion) > 0;
          
          if (shouldUpdate) {
            showUpdateDialog(result.updateMessage);
          }
        }
      } catch (error) {
        console.error('[PWA] Version check failed:', error);
      }

      checkCount++;
    };

    // 启动时检查一次
    checkForUpdate();

    // 每 10 分钟检查一次
    setInterval(checkForUpdate, checkInterval);
  }
});
```
