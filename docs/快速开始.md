## 项目结构

```
nav-log-system/
├── frontend/          # Vue3 + Nuxt3 前端
├── backend/           # NestJS + Prisma 后端
└── docs/             # 文档
```

## 环境要求

- Node.js 18+
- PostgreSQL 12+
- npm 或 pnpm

## 数据库准备

### 1. 创建数据库

```sql
CREATE DATABASE navlog;
CREATE USER navlog WITH PASSWORD 'NavLog2026!@#';
GRANT ALL PRIVILEGES ON DATABASE navlog TO navlog;
\c navlog
GRANT ALL ON SCHEMA public TO navlog;
```

### 2. 配置数据库连接

修改 `backend/.env` 文件中的数据库连接信息：

```env
DATABASE_URL="postgresql://navlog:NavLog2026!@#@localhost:5432/navlog?schema=public"
```

## 后端启动

```bash
cd backend
npm install
npx prisma generate
npx prisma migrate dev --name init
npm run start:dev
```

后端服务将在 http://localhost:3000 启动

### 初始化测试数据

启动后端后，调用以下API初始化测试数据：

```bash
# 初始化用户
curl -X POST http://localhost:3000/api/auth/init-users

# 初始化船舶
curl -X POST http://localhost:3000/api/ships/init
```

测试账号：
- 岸基主管：shore_crew / admin123
- 船舶政委：ship_political / admin123
- 测试用户：gogotb / 123456

## 前端启动

```bash
cd frontend
npm install
npm run dev
```

前端服务将在 http://localhost:3001 启动
